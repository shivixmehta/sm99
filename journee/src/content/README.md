# Content packs

Offline JSON content, so Journée works without the AI. Each pack is added in its Section's build phase:

- `stoic-passages.json` (Phase 8): public-domain translations only, each with author, work and reference
- `recipes.json` (Phase 7): seed Mauritian & French dishes and drinks (alcoholic ones flagged)
- `french-core.json` (Phase 6): core vocabulary deck for SM-2 flashcards
- `puzzles/` (Phase 9): puzzle generators (code, not JSON)
